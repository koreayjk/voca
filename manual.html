단체장(원장) 사용 설명서

학원·학교·공부방에서 IM VOCA를 단체로 운영하는 원장님을 위한 안내서입니다. 학생을 받고, 단어장을 배정하고, 매일 학습 현황을 자동으로 보고받는 방법을 기능별로 정리했어요.

01

시작하기 — 단체 만들고 학생 받기

회원가입할 때 ‘단체’를 선택하면 단체장(원장)으로 시작합니다. 단체를 만들면 학생 초대용 가입 코드가 자동으로 생겨요.

단체 만들기

  1. 회원가입 시 🏫 단체 선택 → 로그인 후 단체 관리 화면으로 이동해요.
  2. 단체 이름(예: OO영어학원)을 입력하고 ‘단체 만들기’를 누르면 끝. 가입 코드가 자동 발급돼요.

학생 초대하기

  1. 왼쪽 메뉴 🎫 초대 코드에서 가입 코드를 확인하고 복사하세요.
  2. 학생에게 코드를 전달해요. 학생은 회원가입 때 ‘단체’를 고르고 이 코드를 입력하면 우리 단체로 들어와요.
  3. 가입한 학생은 승인 대기 상태로 들어옵니다 → 학생·관리자 탭에서 승인해 주세요.
⚠️
코드가 유출됐을 땐 ‘재발급’을 누르면 새 코드가 생기고 이전 코드는 즉시 무효가 돼요. 기존 학생에는 영향이 없습니다.
02

대시보드 — 한눈에 보는 현황

📊 대시보드 메뉴는 단체 상태를 요약해서 보여줘요. 매일 여기부터 확인하면 됩니다.

학생 — 승인된 학생 수 승인 대기 — 처리할 학생 수 관리자 — 주·공동 관리자 수 월 예상 — 이번 달 예상 청구액

그 아래 ‘오늘의 리포트’가 자동으로 떠서, 오늘 학생들이 복습을 했는지·과제를 하고 있는지 한눈에 보여줘요. (자세한 내용은 6. 학습 리포트)

03

학생·관리자 관리

👥 학생·관리자 메뉴에서 구성원을 관리합니다. 승인, 담당 선생님 지정, 공동관리자 임명, 내보내기를 모두 여기서 해요.

① 승인 대기 학생 처리

코드로 가입한 학생은 목록 상단에 승인 대기로 표시돼요. 승인하면 우리 단체 학생이 되고, 거절하면 들어오지 못해요.

② 담당 선생님 지정

학생 옆 드롭다운에서 담당 선생님(공동관리자)을 지정할 수 있어요. 담당쌤은 자기 담당 학생만 리포트를 받고 관리해요 — 반별·담임제 운영에 딱 맞아요.

③ 공동관리자 임명

  1. 선생님으로 쓸 학생 옆 🛡️ 공동관리자 버튼을 누르면 그 사람이 관리 권한을 갖게 돼요.
  2. 공동관리자는 학생 승인·단어장 배정·리포트 열람을 함께 할 수 있어요. (단어장은 그대로 사용 가능)
ℹ️
주 관리자(원장)는 단체 전체를 관리하고 결제를 진행해요. 공동관리자(선생님)는 학생 승인·배정·자기 담당 학생 리포트를 맡아요. 임명은 언제든 해지할 수 있어요.
04

단어장 배정 — 두 가지 방법

학생에게 단어장을 과제로 줄 때, 상황에 따라 두 방향 중 편한 걸 쓰세요. 배정하면 학생 앱에 ‘📌 과제’로 바로 떠요.

여러 학생 → 한 번에

책에서 배정하기

책 한 권을 반 전체·여러 학생에게 동시에 줄 때. 책을 열고 ‘🏫 이 책을 학원생에게 배정’ → 대상 선택.

한 학생 → 여러 권

학생에서 배정하기

특정 학생에게 맞춤으로 여러 책을 줄 때. 학생을 눌러 상세 → ‘📚 단어장 배정’ → 책 여러 권 선택.

책에서 배정 (다수 배정)

  1. 배정할 책(또는 특정 페이지)을 열어요. 책 → 🏫 배정 / 페이지 ⋯ → 이 페이지 배정
  2. 대상 선택 — ‘학원 전체 승인 학생’ 또는 ‘학생 선택’(체크). 마감일(선택)도 지정할 수 있어요.
  3. 배정하기를 누르면 끝. 다시 열면 이미 배정된 학생은 ✓ 배정됨으로 표시돼요.

학생에서 배정 (개별 맞춤)

  1. 학생·관리자 탭에서 학생을 눌러 상세를 열어요.
  2. 맨 위 ‘📚 이 학생에게 단어장 배정’ → 줄 책을 여러 권 체크(공식 단어장 포함) → 배정하기.
💡
이미 배정된 책은 자동으로 ‘✓ 배정됨’으로 표시돼서 중복 배정되지 않아요. 같은 책을 여러 학생에게 줘도 리포트는 한 줄로 깔끔하게 모여요.
05

공식 단어장 — 수능·중등·토익

IM VOCA가 만든 기출 빅데이터 기반 공식 단어장을 학생에게 배정할 수 있어요. 관리자는 학습언어와 상관없이 모든 공식 단어장을 볼 수 있어요.

수능 기본·핵심·고난도·숙어 중등 기초·핵심·완성 토익 기초·핵심·고득점·숙어 스페인어 기초·중급·선교

배정 방법은 일반 단어장과 같아요(위 4번 참고). 공식 단어장을 골라 학생에게 배정하면 됩니다.

🔒
무료 단체는 배정받은 공식책의 Day 1만 열려요(체험). 결제한 학원은 학생 전원이 모든 Day를 무제한으로 봅니다. (결제는 7번 참고)
06

학습 리포트 — 자동 보고

학생을 일일이 안 들어가도, 누가 복습을 제대로 하고 있는지 자동으로 보고받아요. 📈 리포트 메뉴에서 확인합니다.

오늘의 리포트 (매일 자동)

매일 밤 9시에 학생별 현황이 자동으로 정리돼요. 걱정되는 학생(밀린 복습·오늘 안 함)이 위로 올라와서 챙기기 쉬워요.

✅ 공부함 / 🔁 복습 N ⚠️ 오늘 안 함 ⛔ 밀린 복습 N 📝 과제 3/6 📖 개인공부 · 🔥 연속일수

과제(배정한 책)와 학생이 개인적으로 올린 공부를 구분해서 보여줘요. 담당쌤(공동관리자)은 자기 담당 학생만 보여요.

과제별 상세 리포트

📈 리포트 메뉴를 누르면 바로 떠요. 배정한 과제마다 학생이 며칠차 복습 중인지, 제때 했는지 / 늦었는지가 보이고, 학생별 학부모 공유 카드도 보낼 수 있어요.

시작 전복습 중복습 완료 제때 ✅늦음 ⚠️
07

구독·결제 — 학원 프리미엄

💳 구독·결제 메뉴에서 학원 전체를 무제한으로 열 수 있어요. 결제는 주 관리자(원장)만 진행합니다.

요금

  1. 원장(주 관리자)은 무료예요.
  2. 선생님·학생은 1명당 월 $2.99 — 매달 승인된 인원수만큼 자동 청구돼요.
  3. 결제하면 학원 전원이 사진 스캔 무제한 + 공식 단어장 전체 Day가 열려요.
💡
학생이 중간에 늘거나 줄면 다음 결제에 인원수만큼 자동으로 반영돼요. 별도 조작이 필요 없어요.
08

복습 시스템 — 망각곡선과 점수

IM VOCA는 에빙하우스 망각곡선에 따라 복습 일정을 자동으로 잡아줘요. 학생이 처음 외운 날을 기준으로 다음 복습일이 정해집니다.

암기→ +1일→ +2일→ +3일→ +6일→ +15일→ +30일

늦게 복습하면?

예정일을 넘겨서 복습하면 그 회차의 점수는 없어요(0점). 대신 그날 기준으로 다음 차수 복습이 정상 등록돼요.

🗓️
예시 — 5일에 처음 외웠으면 6일이 1일차 복습이에요. 6일에 안 하고 7일에 하면 점수는 0, 그리고 8일이 2일차 복습으로 세팅됩니다. 학생 완료 화면에도 “예정일이 지나 점수 없음”이 안내돼요.

→ 제때 복습하는 습관을 만들도록 설계했어요. 늦어도 진도는 계속 나가되, 점수는 정시 복습에만 줍니다.

09

자주 묻는 질문

학생에게 배정한 단어장은 학생 화면 어디에 뜨나요?
학생 앱 책장 상단의 ‘📌 과제’ 목록에 떠요. 학생이 눌러서 바로 외우고 복습할 수 있어요.
공동관리자와 주 관리자는 뭐가 다른가요?
주 관리자(원장)는 단체 전체 관리 + 결제를 담당해요. 공동관리자(선생님)는 학생 승인·배정·자기 담당 학생 리포트를 맡아요. 결제는 주 관리자만 가능합니다.
오늘의 리포트가 안 보여요.
매일 밤 9시에 자동 생성돼요. 그 전에는 전날 리포트가 최신으로 보여요. 승인된 학생이 있어야 표시됩니다.
무료로도 학생에게 배정할 수 있나요?
네. 배정은 무료로 됩니다. 다만 무료 단체는 학생이 공식 단어장의 Day 1만 볼 수 있고, 결제하면 전체 Day가 열려요.
담당 선생님을 바꾸거나 학생을 내보내려면?
학생·관리자 탭에서 학생 옆 드롭다운으로 담당을 바꾸고, ✕ 버튼으로 내보낼 수 있어요(계정·단어 데이터는 보존).
