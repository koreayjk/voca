사용자 결정 2026-11-26. 페이스북은 한국어를 접고 **스페인어**로 간다.

> **같은 날 재조정:** 틱톡을 **영어권으로 옮겼다** (`english-market.md`).
> 계정이 미국 등록이라 틱톡의 첫 배포가 영어권으로 가고, 팔로워가 0명이라
> 지금 바꾸는 비용이 0이었다. 스페인어는 페이스북이 맡는다 — 미국 히스패닉
> 커뮤니티 사용률이 높고, 인스타와 달리 **본문 링크가 클릭된다.**
> 이 파일의 대본 E1~E5 는 그대로 페이스북용으로 쓴다.

---

## ⚠️ 가장 중요한 것 — 한국과 **파는 물건이 다르다**

한국에서 파는 것은 **단어장**이다. 4,800단어가 Lv.1~12로 정리돼 있고 하루 20개씩
외운다. 수능이 있으니 그 상품이 성립한다.

**스페인어권에는 그 습관이 없다.** 단어장(단어 묶음을 사서 외우는 상품)은
한국·일본(単語帳)·중국(单词书) 특유의 물건이다. 중남미·미국 히스패닉은
Duolingo, 어학원, 수업 노트, Quizlet 으로 공부한다.

그래서 **"4.800 palabras · Nivel 1~12" 를 그대로 번역하면 안 된다.**
번역은 맞는데 포지셔닝이 틀린다. (2026-11-26 커버를 그렇게 만들었다가 바로 고쳤다)

### 대신 파는 것 — **원서를 읽을 때 쓰는 단어 앱**

```
영어로 뭔가를 읽는다 → 모르는 단어에서 멈춘다 → 페이지를 찍는다
→ 그 단어들이 단어장이 된다 → 까먹기 직전에 다시 나타난다
```

이게 전 세계에서 통하는 형태다. 책·기사·논문·자막 — 읽을 거리는 어디에나 있다.

### 왜 이게 우리 자리인가

| | |
|---|---|
| **Duolingo** | 레슨을 준다. 내가 지금 읽는 책은 못 도와준다 |
| **Quizlet · Anki** | 카드를 **손으로 직접 입력**해야 한다 |
| **킨들 사전** | 뜻은 보여주지만 **다시 안 보여준다** → 그대로 까먹는다 |
| **IM VOCA** | **사진 한 장** → 카드 자동 생성 → **까먹기 직전에 다시** |

### 코드가 이미 그렇게 만들어져 있다 (확인함)

`buildScanPrompt()`:
- 난이도 기준에 **"C1: 대학/원서 수준 고급 어휘"** 가 명시돼 있다
- 주석: *"원어민이 일상에서 쓰는 '쉬운 단어의 다른 뜻'은 사전만 봐서는 절대
  모른다 — 예: The Catcher in the Rye 의 'I went down to the can' 은
  깡통이 아니라 화장실"* → 소설을 읽는 사람을 위해 설계됐다

**결정적 차이:**

| | 지원 언어 |
|---|---|
| 공식 단어장 (`voca_word_i18n`) | **4개** — ko · es · ja · zh |
| **AI 스캔** (`PROMPT_LANG_NAMES`) | **10개** — ko · en · es · zh · ja · fr · de · pt · vi · id |

**AI 스캔은 언어쌍을 가리지 않는다.** 공식 단어장만 한국 제품이고,
스캔은 처음부터 글로벌 제품이었다. 비한국어 시장의 주력은 스캔이다.

## 채널 역할 분담

| 채널 | 언어 | 주력 메시지 | 발행 |
|---|---|---|---|
| 틱톡 | 영어 | → `english-market.md` | 사용자가 폰으로 직접 |
| **페이스북** | 스페인어 | 같음 | Mirra 자동 |
| 인스타 · 유튜브 · 스레드 | 한국어 | 수능 단어장 | Mirra 자동 |

페이스북을 스페인어로 돌린 이유: 미국 히스패닉 커뮤니티 사용률이 높고,
**인스타와 달리 게시물 본문 링크가 클릭된다.** 스페인어 유입을 실제로
받아낼 수 있는 유일한 자동 발행 채널이다.

**언어를 섞지 않는다.** 스페인어 인스타가 필요해지면 별도 계정을 만든다.

### 랜딩 주소가 스페인어를 강제한다

`/fb` 는 모국어를 **스페인어로 설정한 뒤** 앱을 연다. (`/tt` 는 영어로 바뀌었다)
미국 히스패닉은 **폰 언어가 영어인 경우가 많다.** 영어로 잡히면 공식 단어장이
숨겨지고 레벨 테스트까지 막혀 '빈 책장'만 보게 된다 — 막다른 길이다.
설정 화면에서 직접 고른 적이 있는 사람은 그 선택을 존중한다.

## 스페인어 대본 큐

전부 **세로 20초 · 첫 3초 훅 · 20~30대 성인 · 읽는 장면**.
교실·학원·교복이 아니다. **책·기사·자막·카페·침대·지하철**이다.

| # | 대본 | 상태 | 파일 | 날짜 | 장면 |
|---|---|---|---|---|---|
| E1 | 30쪽에서 멈춘 책 | todo | | | 침대, 먼지 쌓인 영어 소설 |
| E2 | 사전 찾고 또 까먹음 | todo | | | 카페, 폰 사전과 책 사이를 오감 |
| E3 | 자막 없이 보려 했는데 | todo | | | 소파, 넷플릭스 영어 자막 |
| E4 | 면접 전날 기사 읽기 | todo | | | 밤, 노트북으로 영문 기사 |
| E5 | 같은 단어를 세 번째 찾음 | todo | | | 지하철, 또 그 단어 |

### E1 · 30쪽에서 멈춘 책
```
훅   침대 옆에 먼지 쌓인 영어 소설. 30쪽에 끼워진 책갈피.
     "Llevo tres meses en la página 30."
전개 펼친다 → 모르는 단어에서 또 멈춤 → 한숨
     폰으로 페이지를 찰칵 → 단어들이 카드가 된다
결과 며칠 뒤, 그 단어가 다시 뜬다 → 이번엔 안다 → 계속 읽는다
CTA  "Foto a la página. Nada más."
```

### E2 · 사전 찾고 또 까먹음
```
훅   "Lo busqué ayer. Y hoy otra vez."
전개 "El cerebro borra 7 de cada 10 en un día"
     까먹기 직전에 다시 띄워주는 화면 · 1·2·3·6·15·30 días
CTA  "6 veces y ya no se olvida"
```

### E3 · 자막 없이 보려 했는데
```
훅   넷플릭스 영어 자막. "Pensé que entendía inglés."
전개 일시정지 → 모르는 단어 → 화면 찰칵
CTA  "Lo que no entendiste, vuelve mañana"
```

### E4 · 면접 전날 기사 읽기
```
훅   밤, 노트북. "Mañana tengo la entrevista."
전개 영문 기사에서 막힘 → 찰칵 → 카드
CTA  "Las palabras de TU texto, no de una lista"
```
> **"내 텍스트의 단어, 남이 만든 목록이 아니라"** — 단어장과의 차이를 한 줄로 찌른다

### E5 · 같은 단어를 세 번째 찾음
```
훅   지하철. 폰 사전에 같은 단어를 또 입력. "¿Otra vez?"
전개 검색 기록에 그 단어가 세 번 → 찰칵 한 번이면 끝났을 일
CTA  "Deja de buscar lo mismo"
```

캡션 스페인어, 링크 `https://imvoca.app/fb` 를 **본문에** 넣는다
(페북은 본문 URL 이 클릭된다). 해시태그는 적게.

### ~~틱톡~~ → `english-market.md` 로 옮김

아래 '폰에서 직접' 방식은 영어권 틱톡에 그대로 적용된다.

### 폰에서 직접 올리는 법 (틱톡 공통)

**API 발행을 쓰지 않는다.** 틱톡은 앱에서 직접 올린 영상을 더 밀어준다
(한국어 4편이 조회 0이었던 원인 중 하나로 본다).

1. 에이전트가 영상을 만들어 `SendUserFile` 로 보낸다
2. 폰에 받아 **틱톡 앱에서 직접 업로드**
3. 앱에서 **유행 음원**을 입힌다 (API 로는 상업용 라이브러리만 가능)
4. **AI 생성 표시**를 켠다
5. **미국 동부 저녁 7~9시**(시카고 저녁 6~8시)에 올린다
