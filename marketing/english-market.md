# 영어권 (미국) — 읽는 아이의 사전

사용자 결정 2026-11-26.

## 파는 것

**영어 원어민이 영어책을 읽을 때 쓰는 단어 앱.** 외국어 학습이 아니다.

```
아이가 소설을 읽는다 → 모르는 단어에서 멈춘다 → 페이지를 찍는다
→ 영영 정의 + 이 문장에서의 뜻이 나온다
→ 까먹기 직전에 다시 나타난다
```

### 다른 두 시장과의 관계

| 시장 | 파는 것 | 번역 필요 |
|---|---|---|
| 🇰🇷 한국 | 수능 단어장 + 학원 | 완료 |
| 🇲🇽 스페인어권 | 원서 읽기 + 스캔 (영어 학습) | 완료 |
| 🇺🇸 **영어권** | **읽는 아이의 사전** (학습 아님) | **불필요** |

영어권은 `voca_word_i18n` 에 영어 번역이 없어도 된다. **스캔만으로 성립한다.**
그래서 추가 비용이 거의 없는 시장이다.

## 증거 — 실제로 돌려봤다 (2026-11-26)

『버드나무에 부는 바람』 1장을 영어→영어로 스캔한 결과:

```
bolted   Past tense of 'bolt': to run away suddenly and quickly.
         The Mole suddenly and quickly ran out of his house.

Hang   💬 figurative
         Here, 'Hang spring-cleaning!' means 'Forget about spring-cleaning!'
         Literally: To suspend or be suspended from above.
         → used differently here

put on 💬 phrasal verb
```

**이게 핵심이다.** 아이가 사전에서 `hang` 을 찾으면 "to suspend" 가 나와서
**더 헷갈린다.** 우리는 "Forget about spring-cleaning!" 이라고 풀어준다.

같은 날 원어민 모드를 넣었다(PR #7): 개수를 억지로 안 채우고,
등급을 `Hardest~Easy` 로 표기하고, 고유명사를 뺀다.

## ⚠️ 아이를 직접 타깃하지 않는다 (COPPA)

미국 **COPPA** 는 13세 미만 대상 서비스에 부모 동의와 데이터 수집 제한을
요구한다. 광고로 아이를 직접 겨냥하는 것도 제한된다.

→ **부모·교사에게 판다.** 어차피 돈을 내는 쪽도 그쪽이다.
→ 영상에 아이가 나와도 **말을 거는 대상은 부모**다.
→ "for kids" 가 아니라 **"for parents of readers"** 로 쓴다.

## 채널 — 틱톡 (2026-11-26 결정)

새 계정을 만들지 않았다. **틱톡을 영어권으로 돌렸다.**

| | 틱톡 사용자 (3자 추정) |
|---|---|
| 미국 | 1.36~1.7억 |
| 멕시코 | 0.65~0.9억 |

계정이 **미국 등록**이라 틱톡의 첫 배포가 영어권으로 간다. 거슬러 올라갈 이유가
없다. 팔로워가 **0명**이라 지금 바꾸는 비용도 0이었다. 스페인어는 페이스북이
맡는다 — 인스타와 달리 **본문 링크가 클릭된다.**

| 채널 | 언어 | 발행 |
|---|---|---|
| **틱톡** | **영어** | 사용자가 폰으로 직접 |
| 페이스북 | 스페인어 | Mirra 자동 |
| 인스타 · 스레드 | 한국어 | Mirra 자동 |
| 유튜브 | 한+영+스 | 다국어 오디오 트랙 |

유튜브는 **영상 1개에 음성 트랙 3개**를 올릴 수 있어 한 채널이 세 언어를 다 받는다.
그래서 영어권에 새 계정이 필요 없었다.

## 랜딩은 `/read` 다 — 앱이 아니다

**영어권만 경로가 다르다.** 게스트는 스캔을 못 하고(`Add Book` 이 로그인 벽),
영어 사용자는 레벨 테스트까지 막혀 있다(공식 Lv.1~12 에 영어 번역이 없다).
앱에 바로 떨어뜨리면 **'빈 책장 + 로그인 벽'** 이 전부다.

```
한국어 · 스페인어   /ig /fb → 비회원이 레벨 테스트를 푼다 → 가치 → 가입
영어 (고치기 전)    /tt → 빈 책장 → "Add Book" → 로그인 벽     ← 막다른 길
영어 (지금)         /tt → /read 에서 실제 스캔 결과를 본다 → 가입
```

`/read` 에 지어낸 문구는 하나도 없다. 전부 2026-11-26 에 실제로 나온 출력이다
(위 '증거' 절과 같은 것). 말을 거는 대상은 **부모**다 — COPPA.

`/tt` → `/read` → 가입 링크까지 `utm_*` 과 `from` 이 그대로 넘어간다.
중간에 끊기면 `members.signup_source` 에 `auto:` 가 안 찍혀 집계가 망가진다.
라이브에서 헤드리스로 확인했다:

```
/tt?utm_campaign=u2
  → /read/?utm_campaign=u2&utm_source=tiktok&utm_medium=bio
  → /?utm_source=tiktok&utm_medium=bio&utm_campaign=u2&signup=1
nativeLang=en  targetLang=en   앱 첫 화면 "Start in 30 seconds"
```
