| | |

## ⚠️ NSFW 필터 — 성인 남성 + 아이 + 밤 가정집

영어판이 **두 번 거절**됐다 (`status: nsfw`, 과금은 안 된다).

```
1차 거절  아빠가 잠든 아이 침대 옆에 쭈그려 앉아 침대 밑으로 손을 넣는다
2차 거절  침실을 통째로 뺐는데도 거절 (아빠 + "child" 언급 + 밤 + 집)
3차 통과  엄마로 바꾸고 아이 언급을 전부 뺐다
```

같은 시각 **한국판(엄마 + 잠든 고등학생)은 한 번에 통과**했다.

**→ 가정집 야간 장면에 성인 남성을 쓰지 마라.** 의도와 무관하게 걸린다.
아이는 화면에 안 나와도 되고, 프롬프트에서 "child" 를 빼도 이야기는 성립한다.

## ⚠️ 어두운 영상은 펀치인으로 살린다 (밝기를 올리지 마라)

한국판 도입부가 **YAVG 29.6** 이었다 — 폰에서 7초 동안 까만 화면이다. 스크롤당한다.

시도한 것:
- `eq=brightness=0.10` → **검정이 회색으로 뜬다.** 더 나빠진다
- `eq=gamma=1.25` → 중간톤만 올라간다. 검정은 유지된다 ✅
- **`crop` 으로 1.78배 당기기** → 피사체가 화면을 채운다. 이게 제일 크다 ✅

```
crop=405:720:202:0,scale=720:1280,eq=gamma=1.25:contrast=1.04
```
암전 구간(0~1.8초)은 아예 잘라냈다. 결과 YAVG 52 → 65, 첫 프레임부터 피사체가 보인다.

## ⚠️ 글자가 나오는 컷은 실제 페이지로 갈아끼운다

영어판 14~17초 클로즈업이 `your eill whisn` / `be the rounplin` 이었다.
**단어 이야기를 하는 영상에서 가장 치명적인 결함**이다.

→ `marketing/test-assets/novel-page-en.jpg` 의 실제 지문을 HTML 로 다시 조판하고
단어 세 개(`discontent` `flung` `bolted`)에 SVG 타원을 연필색으로 얹어 교체했다.
**같은 길이로 갈아끼우면 오디오는 원본을 통째로 다시 map 해서 싱크가 유지된다.**

톤 맞추기가 관건이다. 회색 그라데이션으로 곱하면 **회색으로 뜬다** —
호박색(`#2A2118`)으로 곱하고 `-colorize '#E8C27A' 30%` 를 먼저 먹인다. 목표 YAVG 90.

⚠️ `zoompan` 은 요청한 길이보다 길게 나온다(2.80 → 2.92초). concat 에서
`trim=0:2.80` 으로 다시 잘라야 오디오가 안 밀린다.

## ⚠️ AAC 가 인터샘플 피크를 2dB 올린다

PCM 에서 TP −2.5 로 맞춰도 AAC 인코딩 후 **−0.5** 로 올라온다.
`alimiter` 는 샘플 피크만 잡아서 소용없다.

→ 정규화 **전에** 순간음(문·셔터)을 눌러 헤드룸을 만든다:
```
acompressor=threshold=0.25:ratio=3:attack=5:release=180:makeup=1.6,
alimiter=limit=0.75:level=false
```
그래도 최종 −15.3 LUFS / TP −1.4 근처다. 플랫폼이 정규화하므로 이 정도면 둔다.

## 🔴 모든 영상에 반드시 들어가야 하는 두 장면 (사용자 지시 2026-11-27)

> *"복습하고, 단어뜻이 단순 사전의 의미가 아니라 **그 책에서의 의미**대로 띄워준다는 걸 강조해줘."*

감동형 1차본에 **이게 빠져 있었다.** 문제는 아름답게 보여주는데 **제품이 뭘
돌려주는지가 화면에 없었다** — 엄마가 사진을 찍고 바로 엔드카드였다.
사전형(4번)에는 `Hang` 카드로 들어 있었는데 감동형에서 놓쳤다.

**앞으로 모든 영상은 본편 끝 ~ 엔드카드 사이에 아래 두 장을 넣는다.**

### ① 의미 카드 (2.4초) — 사전 뜻 vs 이 지문에서의 뜻

```
앱이 돌려주는 것
  "…to address the problem of food waste…"
  [사전]        주소
  [이 지문에서는] (문제를) 다루다
  첫 번째 뜻이 아니라, 이 문장에서의 뜻.
```

**이게 우리의 유일한 차별점이다.** 킨들 사전도 Merriam-Webster 도 **첫 번째 뜻**을
준다. 아이가 `hang` 을 찾으면 "매달다" 가 나와서 **더 헷갈린다.**

단어는 **그 시장에서 진짜로 함정인 것**을 고른다:
- 한국(수능): `address` 주소 → 문제를 다루다 / `right` 오른쪽 → 권리 / `can` 깡통 → 화장실
- 영어권: `Hang` 매달다 → 집어치워 / `bolted` 빗장 → 뛰쳐나가다

### ② 복습 카드 (2.0초) — 1·2·3·6·15·30

```
그리고 다시 나타납니다
  address
  [1일][2일][3일][6일][15일][30일]
  까먹기 직전에, 여섯 번.
```

날짜 칩을 **반드시 숫자로 보여준다.** "복습해준다"는 말로는 아무도 안 믿는다.

### 만드는 법 — 크레딧 0

`marketing/cards/payoff.html` 에 두 카드가 다 들어 있다. 쿼리로 고른다:

```
file:///…/payoff.html?lang=ko&kind=mean
file:///…/payoff.html?lang=ko&kind=rev
file:///…/payoff.html?lang=en&kind=mean
file:///…/payoff.html?lang=en&kind=rev
```

Playwright 720x1280 으로 찍어 2.4초 / 2.0초 무음 클립으로 만들고,
본편과 엔드카드 사이에 concat **필터**로 끼운다. 음악 베드만 +4.4초 늘리면 된다.

⚠️ 단어·문장은 **영상마다 바꾼다.** 같은 `address` 를 매번 쓰면 금방 질린다.
HTML 안 `D` 객체의 `sent`/`d1`/`d2`/`word` 만 고치면 된다.
