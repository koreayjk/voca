
## 7. 측정 — 일주일 뒤에 이걸 봅니다

소셜에서 온 사람은 세 군데에 흔적이 남습니다.

```sql
-- ① 어느 채널이 가입을 만들었나
select signup_source, count(*) 가입,
       count(*) filter (where exists (select 1 from voca_activity a where a.user_id=m.id)) 학습시작
from members m
where created_at >= '2026-11-25' and signup_source like 'auto:%'
group by 1 order by 가입 desc;

-- ② 소셜 유입의 레벨 테스트 퍼널 (from='social' = ?lt=1 로 들어온 사람)
select message, count(*) from voca_errors
where kind='lt_funnel' and context='social' and created_at >= '2026-11-25'
group by 1;
```

보는 건 조회수가 아니라 **`started_day1`** 입니다.
`started` 는 많은데 `started_day1` 이 안 늘면, 영상이 아니라 제품이 문제입니다.
